OpenVINO Studio 1.1.6
=====================

Локальный AI-интерфейс для Intel OpenVINO на Windows.
Никаких терминалов: запуск двойным кликом, всё управление в окне приложения.

Что умеет
---------
• Скачивать готовые OpenVINO-модели с Hugging Face (LLM, детекция, классификация).
• Общаться с языковыми моделями локально, с потоковым ответом.
• Загружать изображение и задавать вопрос VLM-модели (Gemma 4, Qwen2-VL, InternVL2).
• Распознавать изображения: YOLO-детекция и классификация ResNet/MobileNet.
• Измерять скорость инференса: задержка, p90, кадры/с или токены/с.
• Конвертировать любую модель Hugging Face в OpenVINO IR (FP16/INT8/INT4).
• Ставить и обновлять компоненты OpenVINO, GenAI, Optimum Intel прямо из интерфейса.
• Хранить модели, кэш и окружение на этом же диске.

Требования
----------
• Windows 10 или 11, 64-бит.
• Python 3.10–3.14 (рекомендуется 3.12/3.13), установленный с python.org.
  При установке отметьте «Add python.exe to PATH» и «py launcher».
• Интернет — для скачивания моделей и установки компонентов. Инференс работает офлайн.
• Свободное место: приложение ~0.5 ГБ, модели от 0.6 до 8 ГБ каждая,
  компонент конвертации ~2–3 ГБ. Диска на 250 ГБ хватит с запасом.
• Intel CPU подходит всегда. Intel GPU/NPU — по желанию, нужны актуальные драйверы Intel.
• Встроенное окно: Qt WebEngine (Chromium). PySide6 (~500 МБ) ставится автоматически
  при первом запуске. Для Linux нужны обычные графические библиотеки (OpenGL/X11/Wayland).

Запуск
------
1. Подключите диск к компьютеру (буква диска может быть любой).
2. Двойной клик по «OpenVINO Studio.vbs».
3. Первый запуск: приложение само создаст окружение runtime\venv (несколько секунд).
   Появится окно прогресса, затем откроется встроенное окно приложения на Qt WebEngine.
   Если встроенное окно недоступно, приложение покажет адрес и журнал (без браузера).
4. Откройте «Инструменты» → «Компоненты» и установите:
   - OpenVINO Runtime (обязательно);
   - OpenVINO GenAI (для чата);
   - Конвертация и квантование (если нужен экспорт своих моделей).
5. Откройте «Модели», выберите модель и нажмите «Скачать». Прогресс виден в панели «Задачи».
6. «Чат», «VLM» или «Изображения» — запускайте модель. Всё готово.

Ярлык на рабочем столе
----------------------
Запустите один раз «Create Desktop Shortcut.vbs» — появится ярлык с иконкой.
Его можно закрепить на панели задач или в меню «Пуск».

Где что хранится
----------------
models\            скачанные и сконвертированные модели
runtime\venv\      изолированное Python-окружение (создаётся автоматически)
runtime\cache\     кэш скомпилированных моделей OpenVINO
runtime\logs\      журналы приложения и первого запуска
runtime\settings.json  настройки, включая HF-токен (хранится локально)
runtime\hf\        служебный кэш Hugging Face

Всё привязано к папке приложения. Можно переносить всю папку целиком на другой
диск или компьютер — путь к моделям хранится относительным. Кладите папку
неглубоко, например D:\OVStudio: это защищает от ограничения Windows на длину
путей при установке Python-пакетов. Если после переноса окружение ведёт себя
странно, удалите папку runtime\venv и запустите приложение снова — оно
пересоздаст её автоматически.

Первый запуск и компоненты
--------------------------
Окружение создаётся на диске, ничего не устанавливается в системный Python.
Компоненты ставятся в runtime\venv через pip. Это может занять время:
Runtime ~250 МБ, GenAI ~120 МБ, конвертация ~2–3 ГБ (PyTorch/Optimum).
Во время установки не отключайте диск и не закрывайте приложение.

Частые вопросы
--------------
Python не найден.
  Установите Python 3.10–3.14 с python.org, отметьте «Add python.exe to PATH»,
  перезапустите «OpenVINO Studio.vbs». Microsoft Store-версия тоже подходит,
  но классический установщик надёжнее.

Windows предупреждает о запуске .vbs.
  Это стандартное предупреждение SmartScreen для скриптов без цифровой подписи.
  Нажмите «Подробнее» → «Выполнить всё равно». Файл можно открыть в Блокноте
  и убедиться: он только находит Python и запускает app\bootstrap.pyw.

Окно не открылось, но процесс идёт.
  Подождите 10–20 секунд (первый запуск). Затем запустите ярлык ещё раз:
  второй экземпляр просто откроет окно уже работающего приложения.
  Если окно так и не появилось, откройте runtime\open-in-browser.url
  или адрес из runtime\server.json. Журналы: runtime\logs\studio.log,
  runtime\logs\bootstrap.log.

Скачивание не начинается.
  Проверьте интернет и свободное место. Для закрытых моделей укажите HF-токен
  в «Настройках». Прокси задаётся там же. Большие модели (4–8 ГБ) качаются
  на скорости сети; прогресс и ETA видны в панели «Задачи».

Чат не отвечает / ошибка загрузки модели.
  Убедитесь, что установлен OpenVINO GenAI и скачана LLM (в библиотеке у неё
  должен быть тип LLM и кнопка «Чат»). Неквантованная модель может не влезть
  в память — берите INT4-варианты. Подробности всегда в «Инструменты» → «Журнал».

Не видно GPU или NPU.
  Установите драйверы Intel Graphics / NPU, перезагрузитесь, нажмите
  «Обновить окружение». CPU доступен всегда.

Хочу удалить всё.
  Закройте приложение («Настройки» → «Выйти»), затем удалите папку приложения
  целиком. Никаких следов в системе, кроме ярлыка на рабочем столе.

Безопасность
------------
Приложение слушает только 127.0.0.1 (локально), наружу ничего не отдаёт.
Модели и диалоги не отправляются в облако. HF-токен хранится в открытом виде
в runtime\settings.json — это локальный файл, не делитесь им.
Сторонние модели распространяются под своими лицензиями (Apache-2.0, AGPL и др.);
проверяйте лицензию на странице модели перед коммерческим использованием.
